# Requirements 需求總管

所有需求的單一入口索引。新增需求時，先在此登錄一列，再建立對應資料夾。

- 資料夾與文件命名規則詳見 [Requirements 需求資料夾說明.md](Requirements%20需求資料夾說明.md)
- 路徑格式：`requirements/{年度}/【需求編號】_需求單位_需求名稱/`

## 狀態定義

| 狀態 | 說明 |
| --- | --- |
| 需求探索 | 已收到需求書，尚未完成異動評估 |
| 規格開立 | 異動評估書撰寫中 |
| 開發中 | 評估完成，已進入開發 |
| 測試中 | 開發完成，SIT / UAT 進行中 |
| 已上線 | 已部署至正式環境 |
| 已取消 | 需求單位撤案或停止推進 |

## 知識庫同步定義

需求**上線後**，需由指定人員將本次異動回寫至 [library/](../library/)（`system_overview.md`、`index/functions/`、`index/api_index.md`、`index/downstream_api_index.md`）。此欄用來追蹤該項回寫是否完成。

| 知識庫同步 | 說明 |
| --- | --- |
| — | 尚未上線，還不需要同步 |
| 待同步 | 已上線，等待指派人員回寫知識庫 |
| 已同步 | 知識庫已更新完成（填寫格式：`已同步 / 姓名 / YYYY-MM-DD`） |
| 不需同步 | 本次異動不影響知識庫內容（需於備註說明原因） |
